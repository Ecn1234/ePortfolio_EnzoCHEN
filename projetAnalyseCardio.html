Analyse de profils clients - Cardio Good Fitness

Décembre 2025
Statistique
Analyse descriptive
180 clients
Projet académique - BUT Science des Données

Objectifs

Réalisation d'une étude statistique complète sur un jeu de données clients afin d'identifier les différences de profils selon le genre et le type de produit acheté (tapis de course).

Problématiques

  • Quels sont les profils types des clients selon le genre ?
  • Existe-t-il des différences significatives entre les modèles de tapis de course ?
  • Quelles variables sont corrélées entre elles ?
  • Comment segmenter la clientèle pour mieux cibler les offres marketing ?

Méthodologie

  • Analyse descriptive des variables sociodémographiques
  • Tests statistiques : Welch, Khi-deux, Fisher, Pearson, Spearman
  • Segmentation par modèle de tapis de course
  • Identification des corrélations entre variables

Résultats clés

Différences selon le genre

Les hommes présentent des revenus, une fréquence d'utilisation et une intensité de pratique significativement plus élevés que les femmes.

Segmentation produit

Modèles d'entrée/milieu de gamme (TM195, TM498) → profils similaires
Modèle haut de gamme (TM798) → clients plus aisés, plus diplômés et plus sportifs

Corrélations identifiées

• Forte corrélation entre âge et revenu
• Lien modéré entre revenu et intensité d'utilisation
• Relation entre diplôme et choix du modèle premium

Démarche analytique

1. Analyse descriptive univariée

Première étape : exploration des données avec calculs de moyennes, médianes, écarts-types et visualisations (histogrammes, boxplots) pour chaque variable : âge, revenu, niveau d'éducation, fréquence d'utilisation, intensité de pratique, etc.

2. Analyse bivariée et tests statistiques

Comparaison des profils selon le genre et selon le modèle de tapis de course acheté :

  • Test de Welch : comparaison des moyennes de revenus et d'intensité entre hommes et femmes
  • Test du Khi-deux / Fisher : analyse des relations entre variables qualitatives (genre/diplôme, modèle/produit)
  • Corrélations de Pearson et Spearman : mesure des liens entre variables quantitatives (âge/revenu, revenu/intensité)

3. Segmentation par modèle de produit

Comparaison des trois modèles de tapis de course (TM195, TM498, TM798) pour identifier les différences de profils clients :

  • TM195 et TM498 : profils similaires (clients avec revenus moyens, pratique modérée)
  • TM798 : profil premium (revenus élevés, niveau d'éducation supérieur, pratique intensive)

4. Interprétation et recommandations

Synthèse des insights extraits pour orienter les stratégies marketing :

  • Cibler les hommes pour les produits à forte intensité d'utilisation
  • Adapter les offres selon le profil économique (entrée de gamme vs premium)
  • Développer des campagnes différenciées pour chaque segment identifié
